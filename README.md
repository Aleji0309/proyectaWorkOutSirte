## 📋 Project Description

This project is a multi-section landing page for a fitness or workout business. It was designed to improve layout skills and practice responsive design using only HTML and CSS. The page includes:

- Hero banner  
- Information about training and services  
- Call-to-action buttons  
- Imagery and strong branding sections

It’s optimized for both mobile and desktop devices without using JavaScript.

## 📌 Key Features

- Responsive layout with CSS media queries  
- Modern visual design using colors, typography, and spacing  
- Clean HTML structure with accessibility in mind  
- Static and lightweight site  
- No JavaScript used

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaWorkOutSirte.git
````

2. Navigate to the project folder:

```bash
cd proyectaWorkOutSirte
```

3. Open `index.html` in your browser.

> No installation or build process required — it's a static project.
